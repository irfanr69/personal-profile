# GitHub Pages Deployment

This branch (`gh-pages`) is dedicated to hosting the live version of **Personal Profile Website**.

- Source branch: `terminal-ui`
- Build directory: `dist/`
- Deployment: GitHub Pages

## Updating
1. Checkout `terminal-ui` branch.
2. Run `npm run build`.
3. Push the contents of `dist/` to `gh-pages`.
