---
glossary:
  - term: Ansible
    definition: An open-source automation tool used for configuration management, application deployment, and task automation.
    
  - term: Automation
    definition: The use of technology to perform tasks with reduced human intervention.
    
  - term: Bastion Host
    definition: A special-purpose computer on a network specifically designed and configured to withstand attacks.
    
  - term: Cloud Computing
    definition: The on-demand availability of computer system resources, especially data storage and computing power.
    
  - term: CVE (Common Vulnerabilities and Exposures)
    definition: A list of publicly disclosed computer security flaws.
    
  - term: DMZ (Demilitarized Zone)
    definition: A physical or logical subnetwork that contains and exposes an organization's external-facing services to an untrusted network.
    
  - term: Firewall
    definition: A network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules.
    
  - term: Proxmox VE
    definition: An open-source server virtualization management platform.
---
